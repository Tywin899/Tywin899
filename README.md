### 🚀 Featured Engineering Projects

#### 1. TechAtlas — Engineering Knowledge Search Engine
> **Java** • **Spring Boot** • **PostgreSQL + pgvector** • **Redis** • **Docker** • **Maven** • **BM25** • **HNSW**

A custom-engineered hybrid technical search engine designed to ingest, index, and query documentation, RFCs, GitHub repositories, and engineering content with sub-millisecond retrieval latency.

```
┌───────────────────────────┐      ┌───────────────────────────┐      ┌───────────────────────────┐
│ Ingestion & Normalization │ ───► │ Tokenizer & Porter Stemmer│ ───► │ Positional Inverted Index │
└───────────────────────────┘      └───────────────────────────┘      └─────────────┬─────────────┘
                                                                                    │
┌───────────────────────────┐      ┌───────────────────────────┐                    │
│ User Query: AST Parser    │ ───► │ Boolean Engine(AND/OR/NOT)│ ───► [ BM25 Lexical Ranking ]
└───────────────────────────┘      └─────────────┬─────────────┘                    │
                                                 │                                  ▼
                                        [ ONNX Embedding ]                 ┌─────────────────────┐
                                                 │                         │ Hybrid Re-Ranker    │
                                                 ▼                         └──────────┬──────────┘
                                      ┌──────────────────────┐                        │
                                      │pgvector (HNSW Index) │ ───────────────────────┘
                                      └──────────────────────┘                        ▼
                                                                           ┌─────────────────────┐
                                                                           │ Top-K Precision Hits│
                                                                           └─────────────────────┘
```

* **Inverted Index Engine:** Implemented persistent and in-memory inverted indices with tokenization, Porter stemming, stop-word elimination, and positional posting lists for precise phrase matching.
* **AST Query Processor:** Built an Abstract Syntax Tree (AST) evaluator supporting complex Boolean expressions (`AND`, `OR`, `NOT`), field-aware retrieval, prefix/wildcard search, and synonym expansion.
* **Hybrid Lexical + Vector Retrieval:** Coupled deterministic BM25 ranking with 384-dimensional ONNX dense embeddings indexed via `pgvector` HNSW, yielding robust semantic search capabilities.
* **Production Resiliency:** Built background index hydration, automatic crash consistency repair routines, and Redis caching layers for frequent query acceleration.

#### 2. Adaptive Spatial Risk Modeling System
> **Python** • **NumPy** • **Pandas** • **GeoJSON** • **Bayesian Inference** • **Kalman Filtering** • **Folium**

An intelligent spatiotemporal risk localization platform developed during internship work at **Arsha Consultants** to model dynamic biological risk vectors and optimize IoT physical sensor deployments.

* **Spatiotemporal Diffusion Modeling:** Implemented 2D Gaussian spatial diffusion kernels simulating vector movement across geographic topologies.
* **Bayesian & Kalman Estimation:** Integrated Bayesian priors with recursive Kalman Filter updates to dynamically estimate hotspot probabilities under noisy sensor streams.
* **Active Optimization (Expected Improvement):** Formulated an Expected Improvement (EI) acquisition function to compute optimal relocation trajectories for simulated IoT sensor nodes.
* **Decision Optimization:** Calibrated decision thresholds using ROC/AUC analysis to strictly minimize high-consequence false-negative predictions while bounding false-alarm costs.

---

#### 3. RAG-Based Financial Report Analyser
> **Python** • **FastAPI** • **Streamlit** • **LangChain** • **FAISS** • **HuggingFace** • **Groq LLaMA 3.1**

An automated retrieval-augmented intelligence system built to ingest complex multi-page financial disclosures and provide audit-grade answers with context-grounded citations.

* **Deterministic Document Chunking:** Formulated domain-aware semantic chunking strategies preserving tabular structures and footnote context in financial PDFs.
* **High-Throughput Vector Indexing:** Indexed dense embeddings within a FAISS similarity search structure for sub-50ms top-$k$ nearest neighbor retrieval.
* **Grounded Generative Reasoning:** Integrated FastAPI middleware feeding context-constrained prompts into Groq-hosted LLaMA 3.1 with strict hallucination guards.
